Project 1: hydrogen/H2O radiation data

PROJECT 1: HYDROGEN / H2O NON-GRAY RADIATION
------------------------------------------------------------------------------
What this project does:
  Encodes the Singh & Hostikka H2O Planck-mean absorption correlation and
  stores their published comparison metrics for RCFSK, WSGG, and Planck mean.

Core equation:
  kappa_planck = X_H2O * 3.8821e6 * T^(-1.9811)

Published result summary:
  Radial source peak error: RCFSK <= 14%, WSGG about 43%, Planck mean about 150%.
  Axial wall-flux peak error: RCFSK within 7%.
  Sandia plume side-wall flux: RCFSK about 6%, WSGG about 51%.
  CPU timing table: 4 RTE solves for RCFSK/WSGG vs 1 solve for Planck mean.

Project 2: Johansson particle correlations

PROJECT 2: JOHANSSON PARTICLE CORRELATIONS
------------------------------------------------------------------------------
What this project does:
  Implements Johansson 2017 gray absorption/scattering efficiencies for
  coal/char and two ash compositions fitted to Mie calculations.

Correlation form:
  1 / y^z = 1 / y0^z + 1 / y_inf^z

Why it matters for the Aalto/FDS work:
  The posting emphasizes multi-phase radiation and fuel particles. FDS already
  contains Mie machinery in Source\radi.f90; these correlations are a compact
  bridge from published particle optics into model-development experiments.

FDS integration and portfolio boundary

FDS CLONE: WHAT IT IS AND HOW WE CAN USE IT
------------------------------------------------------------------------------
FDS clone status:
  [OK] Detected fds\Source\radi.f90 in this project folder.
  FDS source snapshot: Fortran 2018 codebase; 33 Source\*.f90 files detected in the clone.
  Radiation verification snapshot: 73 fds\Verification\Radiation\*.fds cases detected.

What FDS is:
  FDS is NIST's Fire Dynamics Simulator: a large Fortran 2018 LES/fire-CFD
  solver for smoke, heat transport, combustion, radiation, particles, walls,
  and verification/validation cases. Smokeview is the companion visualizer.

Relevant files in your clone:
  fds\Source\radi.f90  - radiation heat transfer module.
  fds\Source\rcal.f90  - RADCAL-related gas absorption calculations.
  fds\Source\part.f90  - Lagrangian particles.
  fds\Source\vege.f90  - vegetation/wildland-fire structures.
  fds\Verification\Radiation\*.fds  - 73 radiation verification cases detected.
  fds\Verification\WUI\*radi*.fds   - gas/vegetation radiation consistency cases.

What we can use it for in this portfolio:
  1. Map our Fortran radiation kernels to FDS naming, data structures, and routines.
  2. Use FDS verification cases as examples for future benchmark runs.
  3. Prototype H2O/particle routines outside FDS first, then document where they
     would connect inside radi.f90.
  4. Keep this portfolio honest: it can inspect and align with FDS, but it is
     not yet a patched or validated FDS branch.
